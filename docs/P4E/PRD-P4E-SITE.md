# PRD-P4E-SITE —— 多站点（配额化）+ 删站 + AI 工具多站语义 + sid 日志脱敏

> 编号续接：决策 D51 起（D50 止）、规则 R47 起（R46 止）、任务 T59 起（T58 止）、错误码 40117 起（40xxx 用到 40116）/ 30020（30xxx 用到 30019）。
> 用户决策（2026-09-12）：三项形态问题均「无偏好」，按推荐方案执行并记录依据。

## 1. 背景与目标

P4a 起站点为「每用户一站」（`site_site.user_id` UNIQUE），P4b AI 三件套、P4d 公开语义分流全部建立在该单数假设上。本期解除该假设，改为**配额化多站点**：默认仍 1 个（行为与现状完全一致），admin 可按用户调上限。等级/套餐联动不做（更大立项）。同时补两件欠账：站点删除能力（目前只能停用不能删，删用户被 40112 永久卡死）、P4d 走查观察 2 的 sid 日志脱敏。

**非目标**：等级/套餐体系、AI 建站工具（create_site）、站点间复制/迁移、域名绑定。

## 3. 规则

- **R47 配额校验**：创建站点时 `count(用户站点) >= limit` → **40118**（名义 40117，已顺延，见 §4）；check-then-act 竞态同 T30 口径（个人场景接受轻微超额，不做分布式锁）
- **R48 admin 调整下限**：= 该用户当前站点数（照 T30「下限=used」先例），调低不影响存量站点
- **R49 slug 生命周期**：全局唯一不变；删站后 slug 立即可再注册（行物理删 + 缓存已清）
- **R50 删站确认**：前端二次确认弹窗必须列明——「文章/栏目/标签/评论物理删除不可恢复；站点文件移入回收站可还原；slug 立即释放」
- **R51 多站下的 inSite/isSiteRoot**：语义扩展为「该用户**任一**站点子树 / **任一**站点根」；SiteRootService 签名由单 id 改 id 集合
- **R52 站点根删除保护**（补 P4a 遗留口子）：站点根目录禁止在云盘侧直接删除/移入回收站 → 30020，须先删站点；与 R37 移动保护（30019）配套
- **R53 删站与保护的内部通道**：删站流程经 CloudFacade 专用方法移除站点根（绕过 R52 的用户面保护），属主校验在 site 域完成
- **R54 还原语义**：从回收站还原的原站点根 = 普通文件夹（is_public 保持 1，享受 P4c 公开链接语义）；不再关联任何站点，R45 按钮组按 inSite 自动分流回普通组
- **R55 删站缓存清理**：`DEL site:resolve:{slug}` + `scanDel site:path:{siteId}:*` + `scanDel site:data:{siteId}:*`
- **R56 AI 工具属主边界**：slug 参数只解析当前用户自己的站点；查无此 slug 回喂 **40119**（名义 40118，已顺延）+ 用户现有站点列表，不暴露他人站点存在性
- **R57 AI 建站工具**：`create_site` 为 write 类（确认卡，summarize 摘要 = slug + title）；handler 经 SiteFacade 走 manage 同一创建链，配额满回喂 `{ ok:false, errorCode:40118, limit, used }`、slug 冲突/保留字回喂 40102/40103 让模型换 slug 重试，均不抛栈

## 4. 错误码增量

> **编号修订（2026-09-13 用户拍板：保持代码现状、文档对齐实际）**：本节原定 40117（配额满）/40118（不存在或非属主），但 **40117 已于 P4c 被 `CloudListingDisabled`（该文件夹未开放列表浏览）占用**，且前端公开页 / `FolderView` 硬编码依赖该语义，故 P4e 两码顺延为下表实际编号。`error-code.ts`、ARCHITECTURE §18.7、API §10 均按实际编号书写。

| 码        | 语义                                      | 前端动作               |
| --------- | ----------------------------------------- | ---------------------- |
| **40118** | 站点数量已达上限（message 带 limit/used） | 提示联系管理员调整配额 |
| **40119** | 站点不存在或非属主                        | 提示并刷新站点列表     |
| 30020     | 站点根目录禁止直接删除（须先删除站点）    | 提示                   |

40101 语义收窄：原「未开通 / 已有站点」双含义，多站后「已有站点」场景消失，40101 仅保留「未开通站点」引导语义。

## 5. 验收标准

1. 默认 limit=1 的用户：建站第 2 个 → **40118**（名义 40117，已顺延，见 §4）；其余体验与 P4d 完全一致（回归保护）
2. admin 将某用户 limit 调为 3 → 可建 3 站，slug 各不相同，开放层 `/api/open/{slug}/` 各自独立可访问
3. limit 调回低于现有站点数 → 存量站点不受影响，仅新建被拦（R48）
4. 多站用户在云盘：任一站点子树内文件按钮组均为「设为私有/取消私有」，任一站点根均无公开按钮且移动 → 30019、删除 → 30020（R51/R52）
5. 删站：二次确认后站点数据物理清空、slug 立即可再注册、开放层 40400、根目录出现在回收站且可还原为普通文件夹（R53/R54/R55）
6. 前端：单站用户 5 页行为与现状零差异；多站用户切换器切换后文章/栏目/标签/评论/设置全部跟随；刷新后当前站不丢；当前站被他端删除后自动回退
7. AI：单站用户三件套零参数直通（现状一致）；多站用户省略 slug → 回喂站点列表；指定 slug → 精确命中；指定他人/不存在 slug → **40119**（名义 40118，已顺延）
8. AI write_site_files 确认卡摘要携带目标站点标识
9. 日志脱敏：人为制造一条带 `?sid=` 的 500，winston 日志中 sid 值为 `***`；操作日志链路同口径确认
10. 用户管理「站点配额」按钮：admin 可见可调，common 不可见（site:admin:quota 不含入 common 授权）
