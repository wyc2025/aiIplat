## 1. 阶段概述

本期四块，全部在 cloud 域及前端云盘页：

1. **移动能力**：剪切/粘贴 + 拖拽移动（到文件夹行 / 面包屑上级）
2. **多选批量**：多选模式 → 批量删除 / 批量打包下载 / 批量移动
3. **分享升级**：提取码 + 分享页预览化（对齐公开落地页体验）+ 文件夹分享
4. **公开语义分流**：站点子树内 = 「设为私有」，站点外 = token 公开，双入口互斥

P3 D12「本期不做」的移动/拖拽/批量/打包下载四项本期补齐；提取码为对 P3 D5 的**正式修订**（D47 追认）。

## 3. 功能细则

### F1 剪切 / 粘贴 / 拖拽移动

- 「剪切」入操作列与多选工具栏；剪切后列表行半透明显示；「粘贴」按钮出现在工具栏（有剪切内容时可用）；跨目录粘贴执行移动
- 拖拽移动：行可拖起；**目标高亮**——文件夹行悬停高亮、面包屑项悬停高亮（即可移到上级）；与上传 drop zone 的高亮样式区分（移动=行/面包屑高亮，上传=列表区整框高亮）（D44）
- 移动的公开继承警告（R39，**安全规则**）：目标是站点子树或 token 公开文件夹的子树时，确认框明示「目标目录处于公开状态，移入后内容将对外可见」——由 move 接口响应 `targetPublic: true` 触发前端警告，二次确认后才执行
- 移动后公开性按新父目录重新上溯判定（三态自然语义）；token 挂 fileId 不受影响（D30）
- 非法目标：移入自身/后代、站点根、回收站 → 30019

### F2 多选批量

- 工具栏「批量操作」控制按钮：切换列表复选框列显隐 + 多选工具栏（全选/删除/移动/打包下载/取消）
- 批量删除：确认框 → 前端队列逐条软删（R2 语义不变，进回收站）→ 汇总面板
- 批量移动：复用剪切粘贴链路（批量入剪切板）
- 批量打包下载：多选（文件+文件夹混合）→ `POST /cloud/file/pack-download` → 流式 zip 下载（`iplat-pack-yyyyMMdd-HHmm.zip`）；zip 内保持目录结构、文件名 UTF-8 flag（防 Windows 解压乱码）；管理侧视角打包（不受三态限制——自己的文件自己的包）

### F3 分享升级

- 创建/编辑分享弹窗：新增「提取码」可选项（4~8 位，用户自定义或随机生成按钮）；留空 = 无密码（现状兼容）
- 访客链路：访问分享链接 → 有密码 → 密码门禁页（输入框 + 错误提示 + 剩余尝试次数）→ 通过签发短期凭证 → 进分享页
- 分享页体验（D46）：文件分享 = FileView 分支渲染（视频/音频/图片/PDF/文本预览 + 下载按钮）；文件夹分享 = FolderView（列表 + 下钻 + 单文件预览 + **整包下载**按钮）
- 防爆破（R42）：密码错误按 IP+token 限流，连续错误锁定（口径照登录 10102）
- 分享管理页：列表加「提取码」列（掩码显示）+ 类型列（文件/文件夹）

### F4 公开语义分流（D49）

- 我的文件页按钮组按 `inSite` 分流：站点子树内只显示「设为私有/取消私有」；站点外只显示「设为公开/取消公开/复制公开链接」
- 站点根目录行：无「设为私有」（恒公开锚点；整站关闭走站点 status）
- 旧 `set-public` 接口保留（站点机制依赖），前端普通目录不再暴露其入口——9-10 阻断事故的操作路径消除

| R41  | 打包下载：流式压缩零落盘；范围 = 管理侧自有文件（不受三态限制）；单条目 ≤ CLOUD_MAX_FILE_SIZE，超出条目跳过并记入响应头提示 |
| R42  | 提取码：哈希存储；错误按 IP+token 限流（连续 5 次锁 10 分钟，照 10102 口径）；短期凭证有效期 ≤ 分享剩余有效期               |
| R43  | 文件夹分享动态子树：分享后新增/删除即时反映；is_public=2 阻断项及其子树对外不可见                                           |
| R44  | 分享预览 MIME 口径同 R26：html/htm/svg 强制 attachment，文本强制 text/plain（分享页预览同样不得执行脚本）                   |
| R45  | 公开入口互斥：站点子树内仅「设为私有」，站点外仅 token 公开；站点根恒公开不可设私有                                         |
| R46  | file.list 响应加 inSite 布尔标记（后端上溯经过站点根锚点判定）                                                              |

## 5. 本期不做（P4e 及以后）

- 多站点（P4e：配额化 + AI 工具单数语义改造 + 删站并入）
- 用户等级/会员/支付体系（独立立项，多站点配额联动预留）

## 6. 验收标准

- [ ] 移入站点目录或公开文件夹 → 弹出「对外可见」警告，确认后才执行；移入后按新父目录上溯判定生效（公开可访问 / 移出即不可访问）
- [ ] 多选模式：控制按钮切换复选框；批量删除进回收站（used 不变）；批量移动成功；失败项入汇总面板

- [ ] 提取码：带密码分享 → 访客须输码；错误 5 次锁定 10 分钟；无密码分享行为不变（回归）
- [ ] 分享页：文件分享五类型分支预览 + 下载；html/svg 强制下载不执行；文件夹分享列表可下钻、单文件预览、整包下载
- [ ] 文件夹分享动态子树：分享后向内新增文件访客可见；删除即消失；阻断（is_public=2）子项不可见
- [ ] 语义分流：站点子树内仅见「设为私有/取消私有」且无「复制公开链接」；站点外反之；站点根无「设为私有」
- [ ] 回归：P4c 公开机制（token/落地页/40117）、旧无密码分享、站点开放层访问全部不受影响
- [ ] 双端 build 0 错误、eslint 0；新增依赖仅 yazl（`pnpm why` 无其他新增）
