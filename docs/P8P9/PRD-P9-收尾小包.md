## 1. 决策

- **D79 AI 导入/排版工具接线**：新增 `import_site_article` / `format_site_article` 两个工具，均为 **read 级**（只解析/排版、不落库、不出确认卡），直接包装 P8 已落地的纯函数模块（`article-import.parser.ts` / `markdown-format.ts`），工具内零业务逻辑复写。
- **D80 排版前自动快照 = 纯前端**：不进后端、不进 DB。会话内内存快照 + localStorage 兜底，只留最近一份。
- **D81 SPA 回退按站可配**：站点设置加「SPA 回退」开关（写 `site_site.spa_fallback` = `'index.html'` / `NULL`），收尾遗留 26；开关旁提示旧 hash 路由模板需「重新应用模板」（走既有 apply-template 端点），收尾遗留 27。

## 2. 规则

- **R79 工具口径**：两工具只解析不落库；参数与返回对齐 P8 REST 契约（API §15）：import 入参 `{ fileId }`、format 入参 `{ contentMd, options? }`；错误回喂复用 30001/30012/30013/40001，不抛栈（R57 口径）；归入 **siteCms 组**，`KEYWORD_TO_GROUPS` 补「导入/排版/format」关键词；能力清单（capability.manifest.ts）同源登记；`pnpm check:ai` 全绿。注意：**format 返回的是排版后全文，模型须自行 diff 或直接向用户复述改动统计（stats.rules），不得假装有 diff 视图**——description 里写明「结果需经用户确认后才由用户自行应用，工具不写库」。
- **R80 快照纪律**：键 `iplat:fmt-snapshot:{articleId|'new'}`，值 `{ contentMd, ts }`；「应用排版」时写入（覆盖旧份）；文章**保存成功后清除**；应用排版后编辑器旁出现「撤销排版」按钮（恢复快照内容进 textarea，原生撤销栈仍可用），保存或离开页面后消失；localStorage 读取失败静默降级为仅内存快照。
- **R81 开关纪律**：开关走既有 `PUT /api/site/manage/:id`（body 加 `spaFallback?: string | null`，仅允许 `'index.html'` 或 `null`，其他值 40001）；变更后清 `site:resolve:{slug}` 缓存；NULL = 关闭 = 行为与 P7 前一致（不变量）；开启时若站点 `app.js` 为旧 hash 路由版（无 `<base>` 反推逻辑），前端提示「模板为旧版，需重新应用模板后刷新地址才会生效」，**不自动重应用**（重应用会覆盖自定义修改，必须用户显式触发既有 apply-template 并确认）。

## 4. 验收标准

1. C1：`/about`（真实目录、无斜杠）→ 301 到 `/about/`（R4 语义不回归）；`/article/9`（非目录无扩展名）→ 回退链 200；`/missing.js` → 40400。三场景冒烟留证。
2. C2：访客对「存在但未发表到本站」的文章 POST 评论 → 40400，与读路径同口径。
3. H1：错误码登记表中 40112/40120 只有一个活跃，另一个有取代标注；代码抛出与登记一致。
4. T92：AI 对话「把云盘里 xx.md 导入成文章草稿」→ import_site_article 返回解析结果（不落库，随后模型走 create_site_article 落库）；「帮我把这段正文排版一下」→ format_site_article 返回排版结果与 stats；check:ai 全绿。
5. T93：应用排版后点「撤销排版」→ 正文恢复；保存后刷新页面，撤销按钮不再出现；localStorage 被禁用时功能不报错。
6. T94：存量站点（spa_fallback NULL）打开开关 → `/article/9` 可访问（模板为新版时）；关闭 → 恢复 40400；开关变更后无需重启即生效（缓存已清）；旧 hash 模板站点开启时出现提示文案。

## 5. 明确不做

- 不批量迁移存量站点模板（自定义站点无法安全覆盖，只能用户逐站显式重应用）；
- 快照不做多版本历史、不进后端（那是「文章版本历史」独立需求，未来立项再议）；
- 功能分享市场、AI 对话附件上传、评论楼中楼、自定义域名均不在本期。
