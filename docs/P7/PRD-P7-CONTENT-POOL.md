## 1. 背景与目标

P4e 多站点落地后暴露真痛点：文章/栏目/标签是**站点子实体**（site_id 直挂），导致——

1. **新站空白**：新建站点一行文章都没有，前台查空（用户实测反馈）；
2. **后管无站点选择**：文章表单靠站点切换器隐式归属，用户无法选择/多选发表目标（P4e 范围遗漏）；
3. **删站毁文章**：D55 级联把文章物理删除，站点只是「展示窗口」却承担内容生死。

本期把内容层从站点剥离：**一个内容池，多个展示窗口**——文章/栏目/标签归用户所有，站点通过「发表关联」「栏目显隐」消费内容。顺带做文章路径美化（`/article?id=9` → `/article/9`）。

**非目标**：每站独立栏目（D74 否决）；跨站共享评论（D75 否决）；标签按站显隐（跟随文章）；文章多版本；自定义域名；SPA 回退的用户可配开关（模板驱动，演进预留）；功能分享市场（P8）。

## 3. 规则

- **R75 迁移纪律**：单事务迁移脚本（加列 → 回填 user_id 与 comment.site_id → 建 publish/display 关联 → 计数校验 → drop 旧列）；执行前提示 mysqldump 备份并需确认；任一校验失败整体回滚；迁移后文章/栏目/标签/评论总数与每站文章分布必须前后一致
- **R76 后管口径**：文章表单加站点勾选组（默认勾当前切换站）；文章列表改用户级（siteId 降为可选筛选），行内显示已发表站点 chips + 每站置顶开关；栏目管理用户级 + 每栏目站点显隐配置（新栏目默认全部站点可见）；建站表单加「将已有文章发表到此站」（默认全选已发布文章）。**细化（正式化新增）**：内容三页（文章/栏目/标签）从站点切换器**解绑**（用户级页面不再注入 siteId）；评论页保留切换器（D75 按站隔离）
- **R77 开放层与工具口径**：开放层 articles/columns/comments 按新关联过滤；文章详情未发表到该站 → 40400 统一口径（不暴露文章存在性）；AI 工具签名调整（见 API §14.5）。**细化（正式化新增）**：`create_site_article` 的 siteIds 缺省行为分档——**status=0（默认草稿）免选站**（siteIds 缺省为空，先躺进内容池，发表随时可补）；**status=1 必须解析发表目标**（slug 指定即用 / 单站直通 / 多站 needSitePick，走既有 resolveSiteForTool 四分支）；`publish_site_article` 全局上下架，上架时若零发表站，摘要带警示「已发布但未发表到任何站点」
- **R78 路径回退口径**：回退仅对无扩展名 GET 生效；入口文件必须真实存在且走既有 CSP 沙箱/MIME 白名单/ETag 输出（回退不扩大 MIME 暴露面、路径穿越校验沿用既有）；带扩展名未命中 → 40400 严格；站点无 spa_fallback（模板未声明）→ 行为不变，不产生软 404；**回退命中与目录命中不写负缓存**（沿用 P4a T35 负缓存教训）；开放 API 数据端点契约不变

## 4. 验收标准

1. **迁移**：前后文章/栏目/标签/评论总数一致；原每站文章分布与 publish 关联一致；无孤儿 user_id/site_id；备份可恢复演练一次；人为制造校验失败 → 整体回滚、数据零变化
2. **内容池可见性**：文章发表到 A、B 两站 → 两站前台均可见；取消 A 站发表 → A 站详情 40400、B 站正常；全局草稿在任何站不可见
3. **栏目显隐**：B 站隐藏栏目 → B 站栏目树无此栏目、该栏目文章在 B 站归入「全部」；开放层栏目 articleCount 只计已发表到本站的文章
4. **删站**：删 A 站 → 文章/栏目/标签本体保留（B 站不受影响）、A 站评论物理删；`DELETE /api/site/manage/:id` 响应与 delete_site 工具摘要均明示「下架不删本体」
5. **建站 onboarding**：缺省 `"all"` → 新站立即有内容（全部已发布文章 + 全部栏目可见）；`[]` → 空站；`number[]` → 仅指定文章
6. **后管**：文章表单站点勾选（默认勾当前切换站）、列表 chips + 每站置顶、栏目显隐配置弹窗均可用；内容三页不受切换器影响，评论页仍按切换器过滤
7. **AI 选站语义**：多站下「写篇文章」→ 默认草稿**免选站**直接落池；「直接发布」→ needSitePick 追问站点；「把《xx》也发表到 B 站」→ update siteIds 确认卡含站点增删；「发到所有站点」→ siteIds 全选、各站可见
8. **发布语义**：publish_site_article 全局上下架；status=1 但零发表站 → 摘要含「未发表到任何站点」警示
9. **路径美化**：默认模板站点 `/article/9` 可访问且刷新不 404、列表链接均为新形式；`/missing.js` 仍 40400；未声明模板行为不变；回退命中不写负缓存；既有目录 301 补斜杠语义不回归
10. **评论按站**：同一文章在 A、B 两站评论各自独立；对未发表到本站的文章读/写评论 → 40400；P6 的作者回复能力在按站隔离下正常（回复跟随评论所在站）
11. **删用户预检**：有内容（文章/栏目/标签任一行）但无站点 → 40120；有站点 → 40112 不变
12. **真机 E2E**：迁移演练 → 建站（默认带内容）→ AI 写文发两站 → 路径美化地址访问 → 删一站文章仍在，一条链零上游错误；测试数据清理、used 回基线
