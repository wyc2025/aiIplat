# PRD-P6-AI-UX —— 按需注入（手册两段式 + 工具路由）+ 评论代审代回 + 封面通道 + 体验三件套

> 编号续接：决策 D67 起（D66 止）、规则 R69 起（R68 止）、任务 T77 起（T76 止）。错误码预计零新增。
> 用户拍板（2026-09-15）：① 工具下发 = 形态 A 确定性路由 + 手册两段式；② 评论加 AI 代回（新建作者回复能力）；③ @codemirror/merge 铁律 7 特批；④ MCP server 化留 P7 功能分享市场一并讨论。

## 1. 背景与目标

P5 后工具 25 个、手册 1976/2000 字见底。本期解两件事：① **按需注入**——手册与工具 schema 都从「全量静态」改「按权限/场景动态」，为功能持续增长解套；② 把 P5 砍掉的评论能力和挂了几期的体验欠账清掉。

**非目标**：形态 B（meta-tool 搜索路由，触发阈值到达前不做）；MCP server 化（P7 讨论）；评论多级楼中楼（只做一级作者回复）；真实图片上传通道（AI 引用既有图）。

## 3. 规则

- **R69 手册分段口径**：通用版与能力清单分段维护、分段核查；能力清单逐项一行（`能力名：一句话 + 关键约束`），注入条件 = 用户持有对应权限标识；无权限项不出现（AI 不会向用户承诺做不到的事）
- **R70 路由分组纪律**：分组表为代码常量（工具名 → 组），新工具注册必须归组（T 系验收含孤儿工具检查）；关键字 → 组映射同文件维护；命中多组取并集；路由不改变权限过滤（先权限过滤、再组路由，两道串联）
- **R71 评论回复口径**：回复公开可见的条件 = 评论本身 audit_status=1；回复不单独审核（作者行为）；访客流与详情缓存失效沿用既有 comment 写路径；AI 代回确认卡摘要 = 原评论昵称/内容截断 + 回复内容
- **R72 封面校验**：`coverPath` 必须 `media/` 前缀 + 解析到当前用户该站点 media 目录下的真实 cloud_file 行 + 扩展名 ∈ 图片白名单（jpg/jpeg/png/gif/webp）；任一不满足回喂 40105 口径让模型换图
- **R73 diff 视图边界**：只读对比（旧 ↔ 新），不做编辑合并；入口 = 编辑器保存有服务端更新冲突时 + AI write_site_files 覆盖确认卡「对比」按钮（后者可降级为纯文本对照，以确认卡形态为准）；merge 包按需异步加载（照 FileEditorDialog 语言包先例）
- **R74 新工具归组**：本期新增 3 个评论工具（list/audit/reply）归入「站点 CMS 组」；工具总数 25 → 28

## 4. 验收标准

1. 手册：admin（全权限）与无角色用户（3 个登录级工具）的 system prompt 实测不同——后者不含任何站点/云盘能力行；分段核查脚本通过（通用版/清单/总长三阈值）
2. 路由：「帮我写篇文章」→ 实算日志显示命中 CMS 组、下发工具数 < 全量且含 create_site_article；「今天天气」类无命中 → 全量兜底；路由 + 权限串联后无角色用户仍只 3 个
3. 孤儿工具检查：新注册工具未归组 → 启动告警（或单测失败）
4. 评论代审：「帮我看看有没有待审评论」→ list 真实数据；批量通过确认卡 → 开放层可见；批量 >20 → 40001
5. 评论代回：确认卡含原评论摘要 + 回复内容 → 确认后开放 API 返回 reply 字段、默认模板页面渲染「作者回复」；重复回复 = 更新不新增行
6. 封面：「用我 media 里的 xx.png 做封面」→ create/update 成功且开放层文章卡片显图；伪造路径/非图片/他人文件 → 40105 回喂不抛栈
7. 模板预览图：模板卡片显示预览图（3 套模板均有），缺图模板降级为占位不报错
8. diff 视图：编辑器内改动后唤出对比，左右/内联差异正确高亮；包异步加载不阻塞首屏
9. 格式按钮：选中文本点粗体/斜体/链接，插入正确 markdown 语法
10. 回收站不再出现 `avatar-*.png` 行；既有删除确认框取消后 console 零告警（全仓统一）
11. 真机 E2E（真实模型）：审评论 → 回评论 → 写文章带封面 → 发布，一条链走完无上游错误
