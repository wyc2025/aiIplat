## 1. 阶段概述

本期三件事，全部为 cloud 域增强：

1. **文件/文件夹公开**：任意位置的文件/文件夹可设为公开，获得长期有效的公开链接；访客免登录打开**落地页**在线消费（视频可播、图片可看、附下载按钮）
2. **批量 + 拖拽上传**：云盘文件列表支持拖入多个文件上传，队列化执行
3. **在线解压**：zip 文件一键解压到同目录

### 1.1 概念分工（用户定稿，防混淆）

|      | 文件分享（P3 已有，不动）                           | 文件公开（本期新增）                        | 功能分享（远期愿景）  |
| ---- | --------------------------------------------------- | ------------------------------------------- | --------------------- |
| 目的 | 让人**下载**拿走                                    | **在线消费**，打开就能看/听/读              | 别人克隆你的功能去用  |
| 载体 | cloud_share 随机 token（有效期/可停止/visit_count） | cloud_file.public_token（长期，取消即轮换） | 公开 token + 克隆动作 |
| 体验 | 访客分享页 → 下载                                   | 落地页 → 在线播放/查看 + 下载入口           | 克隆到我的云盘        |

两者 UI 分入口、底层分存储、互不干扰。一个文件可以同时有分享链接和公开链接。

### 1.2 文件类型支持：三层架构

1. **通用落地页（本期核心）**：一个极简公开页面，按类型分支渲染（video/audio 用原生 controls，自带播放/暂停/倍速/进度；img 直显；PDF 内嵌；其他类型显示图标 + 文件名）；所有类型统一带「下载」按钮
2. **raw 裸流**：`raw` 端点向站点页面/自定义页面供水——用户（或 AI 代写）在自己站点写任意体验页面，直接引用公开文件 raw 直链。本期只提供端点与契约说明，不专门开发页面
3. **文件夹列表页**：公开文件夹的访客列表页，默认开启，可关

## 3. 功能细则

### F1 文件/文件夹公开（管理侧）

- 入口：我的文件页操作列「设为公开」（既有按钮扩展）/「取消公开」「复制公开链接」
- 文件设公开：直接生成 token，响应返回公开链接
- 文件夹设公开：弹窗含「允许访客浏览文件列表」开关（默认开），确认后生成 token
- 取消公开：确认框提示「旧公开链接将立即失效，重新公开会生成新链接」
- file.list 响应扩展：`publicToken`、`allowListing` 字段（仅 isPublic=1 时有值），供复制链接
- 权限：复用 `cloud:file:public`，不新增标识
- 「设为公开」动作挂审核门禁开关（CLOUD_AUDIT_ENABLED，默认关、先空转，照 P3 R9 口径）

### F2 公开落地页（访客侧，免登录）

路由（router 静态路由 + 白名单，无布局）：

| 路由                                     | 页面                     | 数据源                                        |
| ---------------------------------------- | ------------------------ | --------------------------------------------- |
| `/view/f/{token}`                        | 文件落地页               | `info` + `raw` + `download`                   |
| `/view/d/{token}`（query `?path=`）      | 文件夹列表页（支持下钻） | `list`                                        |
| `/view/d/{token}/file`（query `?path=`） | 文件夹内文件落地页       | `info?path=` + `raw?path=` + `download?path=` |

文件落地页类型分支：

| 类型                          | 渲染                               | 说明                                                                                     |
| ----------------------------- | ---------------------------------- | ---------------------------------------------------------------------------------------- |
| 视频（mp4/webm/ogg）          | `<video controls>`，src = raw      | 原生控件自带播放/暂停/倍速/进度；拖动依赖 raw 的 Range 支持（复用 T27 streamToResponse） |
| 音频（mp3 等白名单）          | `<audio controls>`                 | 同上                                                                                     |
| 图片（jpg/jpeg/png/gif/webp） | `<img>` 居中自适应                 | ——                                                                                       |
| PDF                           | `<iframe>` 内嵌 raw                | 浏览器内嵌查看器                                                                         |
| 文本（白名单内）              | 预格式化展示（textContent 防 XSS） | 截断展示，完整内容走下载                                                                 |
| 其他类型                      | 文件图标 + 文件名 + 大小           | 仅提供下载                                                                               |

- 所有分支统一带「下载」按钮（走 download 端点，attachment + 原名）
- 失败态：token 无效/已取消/已删除/被阻断 → 统一 404 提示页（不区分原因，防探测口径）
- 页面极简：文件名 + 内容区 + 下载按钮，无平台导航、无 SEO 诉求（`noindex`）
- allow_listing=0 的文件夹：访问列表页 → 提示不开放浏览；知道完整路径的子文件落地页仍可访问

### F3 批量 + 拖拽上传

- drop zone = 文件列表区域（拖入高亮边框反馈），不做全页面拖拽
- 多选文件入队列，**并发 3** 逐个调既有上传接口；单文件失败不阻塞队列
- 每文件独立进度条 + 队列总进度
- 同名逐条走 R4 自动"(1)"，队列结果显示**最终落盘名称**
- 完成后汇总面板：成功 X / 失败 Y，失败项列原因（配额 30003 / 单目录 500 项 30006 / 超限 30004 等）
- 拖入内容含文件夹 → 提示「暂不支持文件夹拖拽，请压缩后上传或使用在线解压」（与 F4 形成话术闭环）
- 上传中刷新/离开页面 → beforeunload 提示
- 上传请求 `timeout: 0`（沿用用户已修复的口径）

### F4 在线解压

- 入口：zip 文件（扩展名 .zip 且 size ≤ CLOUD_MAX_FILE_SIZE）操作列「解压」按钮，`v-permission cloud:file:upload`（解压本质是写入）
- 流程：点击 → 确认框（提示解压目标 = 同目录/包名文件夹）→ loading（`timeout: 0`）→ 完成提示（文件数/总大小）并刷新列表
- 安全四件套（R29）：
  1. **Zip Slip 拦截**：逐条目标名校验，含 `..` / 绝对路径 / 反斜杠开头 → 整个包拒绝（30016）
  2. **双上限**：条目数 ≤ `CLOUD_UNZIP_MAX_ENTRIES`（默认 5000）；解压累计总大小 ≤ `CLOUD_UNZIP_MAX_TOTAL_SIZE`（默认 500MB）且 ≤ 用户配额余量（30003）；边解边累计，超限即中断（30015）
  3. **GBK 文件名解码**：条目名非 UTF-8 flag 时按 GBK 解码（iconv-lite）
  4. **嵌套 zip 不递归**：解出的 zip 就是普通文件
- 事务语义（D36）：先全量落 tmp 区 → 全部成功 → 批量 moveToStorage 转正 + 事务落库（cloud_file 批量行 + used 记账 R3）→ 任何一步失败清理全部半成品，零残留
- 单目录 500 项上限（30006）、目录深度上限（R6）逐条生效

## 6. 验收标准

- [ ] 文件设公开 → 获得 `/view/f/{token}` 链接，无痕窗口免登录可打开落地页
- [ ] 视频落地页：播放/暂停/倍速/拖动进度正常（raw 响应 206 + Content-Range）；下载按钮得 attachment 且文件名与原名一致（含中文名）
- [ ] 图片/PDF/音频/文本/其他 五个类型分支渲染正确
- [ ] html/svg 文件经 raw 访问为 attachment（或 text/plain），浏览器不执行其中脚本
- [ ] 文件夹设公开（默认开列表）→ `/view/d/{token}` 列表页可见子项、可下钻子文件夹、点文件进落地页；关闭列表 → 列表访问 40117，知道完整路径的子文件落地页仍可访问
- [ ] 取消公开 → 旧链接立即 40400；重新公开 → 新 token 新链接，旧链接不再复活
- [ ] 父目录设阻断 → 其下公开文件链接 40400；公开文件移入回收站 → 40400；还原后仍 40400（token 已轮换失效）
- [ ] 分享机制回归：既有分享链接创建/访问/停止/延期不受影响
- [ ] 批量上传：拖入 10 个文件 → 并发 3 执行、同名自动"(1)"、汇总面板数字准确；拖入文件夹出现提示且不产生任何上传请求

- [ ] `nest build` / `vue-tsc` / 双端 eslint 0 错误；新增依赖仅 yauzl + iconv-lite（`pnpm why` 无其他新增）
