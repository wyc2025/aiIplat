# iplat —— P4a 产品需求文档：个人网站·开放站点与文章模块（site 域）

> 本文档是 PRD.md 的 P4a 增补，与 docs/API.md（§6）、docs/ARCHITECTURE-P4A-增补.md 配套使用。
> 前置：P1（后台底座）、P2a（AI 对话+积分）、P2b（AI 工具调用）、P3（云盘）均已完成。
> P4 拆两期：**P4a（本期）= 开放站点托管 + 文章数据模块**；P4b（下期）= AI 编写站点文件 + 在线代码编辑器。

## 1. 需求背景

P4 的总目标是"用户可编程的个人网站"：用户手写（或 AI 写）自己的站点代码，平台托管运行并提供数据能力。P4a 打地基：

1. **云盘公开文件机制**（P3 已规划的方向）：公开目录像 nginx 一样按路径直接渲染访问，与"分享链接（下载语义）"互补；
2. **文章模块**：平台预设的第一个数据模块——多级栏目、标签、文章（查看数/字数/时间）、评论；
3. **开放 API**：用户站点代码获取数据的唯一契约；
4. **站点装配与默认模板**：slug 绑定公开根目录 + 一键创建可用站点，不会写代码的用户有起点，会写的随便改。

云盘是存储与托管底座，site 域是数据与装配层，开放层是两者的访客侧出口。

## 2. 范围

### 本期做

- 云盘公开文件机制：is_public 字段、设为公开/取消公开接口与按钮、覆盖上传（overwrite）
- 开放静态服务：`/api/open/{slug}/*`（路径解析 + 缓存、MIME 白名单、CSP 沙箱、ETag/304、限流、流式）
- 文章模块后端：栏目树（≤3 级）、标签、文章 CRUD（字数统计/发布状态/封面）、查看数
- 评论：访客提交、审核流、开放读取
- 开放数据 API v1：站点信息/栏目树/标签/文章列表/文章详情/评论列表/评论提交
- 站点设置：创建站点（含目录+模板复制）、改 slug/标题/描述/状态/评论开关
- 默认模板四件套（无框架原生 JS，调开放 API 的完整可用站点）
- 后台五页：站点设置、栏目管理、标签管理、文章管理、评论管理
- 删用户预检扩展（SiteFacade.hasSite）

### 本期不做

- AI 编写站点、在线代码编辑器（P4b）
- `/s/{slug}` 短路径、独立域名/子域名、X-Accel-Redirect/CDN 卸载（演进项，架构已预留）
- 用户自建表/动态 API/模块分享（P5 远景）
- 站点主题市场、文章置顶、RSS、评论回复嵌套、评论邮件通知
- 缩略图、分片上传（沿用 P3 遗留清单）

## 3. 功能细则

### 3.1 F1 站点设置（菜单：个人网站/站点设置，site:site:manage）

**未开通态**：引导卡片 + 创建表单（slug、站点标题、描述选填）。创建动作后端一气呵成：校验 slug（R11）→ 云盘根目录建"我的站点"目录（同名自动"(1)"）并设公开 → 建 media/ 子目录 → 复制模板四文件 → 落 site_site 行 → 返回站点信息。

**已开通态**展示与操作：

- 站点访问地址 `{origin}/api/open/{slug}/`（一键复制，新窗口打开）
- 编辑：标题、描述、slug（**改 slug 弹强警告：旧链接全部失效**）、站点状态（启用/停用，停用即全站 404）、评论审核开关（默认开）
- "去管理文件"：跳转云盘"我的文件"对应站点根目录
- 展示站点根目录路径与媒体目录（media/）说明

### 3.2 F2 栏目管理（菜单：个人网站/栏目管理，site:column:list）

- 树形表格（复用菜单/部门页的 tree 模式）：名称、排序值、文章数、创建时间
- 新增/编辑：名称（≤32 字）、父级（el-tree-select，**限 3 级**，选父级时超出层级阻止）、排序值
- 删除保护：有子栏目或有文章 → 40107 阻止

### 3.3 F3 文章管理（菜单：个人网站/文章管理，site:article:list）

**列表页**（ProTable）：标题、栏目、标签、状态（草稿/已发布）、字数、查看数、发布时间、更新时间；筛选：栏目、标签、状态、标题关键词；操作：编辑、发布/下架（site:article:publish）、删除（二次确认"物理删除且连带评论，不可恢复"）。

**编辑页**（新建/编辑共用）：

- 字段：标题（≤100 字）、栏目（单选，必选）、标签（多选，可现场新建）、摘要（≤200 字，留空自动取正文纯文本前 100 字）、封面（上传按钮，落 media/，上传后回显预览）、正文 markdown（textarea 编辑 + 工具栏：插入图片（落 media/ 并插入公开 URL 的 md 语法）/粗体/斜体/链接）
- 右侧/下方实时预览：**复用 MarkdownView 公共组件**（禁 raw HTML，已具备）
- 字数实时统计展示（口径 R14，保存时后端复核落库）

### 3.4 F4 评论管理（菜单：个人网站/评论管理，site:comment:list）

- ProTable：文章标题、昵称、内容（截断）、IP、审核状态（待审核/已通过/已驳回）、提交时间；筛选：状态、文章、昵称关键词
- 操作：通过 / 驳回（site:comment:audit）、删除（site:comment:delete，二次确认）
- 默认视图按"待审核"优先展示（待审置顶或默认筛选待审核）

### 3.5 F5 云盘公开目录（云盘域增量，我的文件页）

- 文件/文件夹行操作新增"**设为公开 / 取消公开**"（按钮权限 cloud:file:public）：设公开弹确认"该目录下所有内容将可通过公开 URL 访问"；取消公开提示"最长 60 秒生效"
- 列表"名称"列对公开项显示「公开」标签（复用 file.list 返回新增 `isPublic` 字段）
- 上传按钮旁新增"覆盖同名文件"复选框（默认关）：勾选后上传携带 `overwrite=1`，同名文件物理替换、URL 不变；提示文案"覆盖不可恢复"

### 3.6 F6 访客站点与默认模板

默认模板行为规格（用户可随意改写的起点，非平台承诺的固定功能）：

- **首页**：站点标题+描述头部、栏目导航条、文章列表（卡片：封面/标题/摘要/发布时间/字数/查看数，分页加载）
- **文章详情**：hash 路由 `#/article/{id}`，markdown 渲染正文（CDN markdown-it，html:false），尾部评论区（列表 + 昵称/内容提交表单，提交后提示"已提交，审核后展示"）
- **页脚**：Powered by iplat
- README.txt：写明站点改造方法、开放 API 清单、三条注意事项（① 一律相对路径引用；② 文件路径即 URL，重命名=改 URL；③ 封面配图传 media/）

## 4. 业务规则（违反任何一条视为 bug）

- **R1 数据隔离**：后台接口（/api/site/*）只操作当前登录用户的站点/栏目/标签/文章/评论；操作他人资源一律按"不存在"处理
- **R2 公开性判定**：静态访问命中文件需同时满足——目标在站点根目录子树内 + 从目标上溯至站点根的**每一级** is_public=1 + 链路上无回收站项（deleted_at 为空）+ 站点 status=1。任一不满足 → 40400
- **R3 路径即 URL**：公开 URL 与云盘路径一一对应；重命名/移动 = 改 URL；路径必须先规范化（拒绝 `..`、空段、反斜杠），防穿越
- **R4 目录解析**：路径以 `/` 结尾 → 取该目录 index.html；路径无匹配文件但匹配目录 → 301 重定向补 `/`（相对引用依赖正确的基址）；目录无 index.html → 40400
- **R5 覆盖语义**：`overwrite=1` 仅对文件生效；命中同名文件 → 物理替换（更新 size/mime/ext/storage_name/update_time，used += 新旧差额，旧物理文件直接删除）；命中同名文件夹或缺省 → 维持自动"(1)"
- **R6 栏目保护**：栏目有子栏目或存在文章（含草稿）→ 删除阻止（40107）；栏目换父级禁止指向自身或后代，且结果不得超 3 级
- **R7 文章删除**：物理删除，连带 site_article_tag 与该文章全部评论；不做回收站
- **R8 查看数**：`GET 文章详情` 时以 `site:view:{articleId}:{ip}` SET NX EX 300 去重，首次命中才 view_count+1；**IP 取 X-Forwarded-For 首段**（反代兼容，信任代理前提写入架构增补）
- **R9 评论**：提交即落库 audit_status=0（待审）；开放层仅返回 audit_status=1；审核开关关闭时新评论直过审（audit_status=1）；限流 10 次/分/IP + 同文章同 IP 60s 一条（40111）
- **R10 站点停用**：status=0 时 `/api/open/{slug}/*`（静态+数据）一律 40400
- **R11 slug**：`^[a-z0-9][a-z0-9-]{2,31}$`，全局唯一；保留字黑名单：api / www / admin / manage / system / open / static / assets / public / login / s / site；违规 40103、撞车 40102；**改 slug 旧链接立即全断**（前端强警告）
- **R12 公开生效延迟**：云盘侧公开性/重命名/移动/删除的公开访问生效延迟 ≤60s（解析缓存 TTL）；site 域自身操作（停用/改 slug/文章发布下架/评论审核）主动失效缓存，即时生效
- **R13 删用户预检**：system 删用户前依次经 cloud `hasFiles`（30011）、site `hasSite`（40112）预检，任一命中即阻止
- **R14 字数口径**：正文 markdown 去除全部空白字符与 markdown 标记符号（# * > ` - [ ] ( ) ! ~ 等）后的字符数，中英文均计 1；仅作展示，前后端不互验
- **R15 开放层纪律**：@Public 免登录；全链路 `Access-Control-Allow-Origin: *`（opaque origin 下一切请求均跨源）；禁挂 @OperationLog；一切失败统一 40400；除评论提交外全部为只读

## 5. 错误码

site 域启用 **40xxx 段（40101 起）**，明细见 API.md §6.1。开放层对外统一 40400（R15）。
