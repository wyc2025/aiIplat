# PRD-P12-PATCH2：数据应用公开面 AI 闭环

> 状态：待实施（随下一实施窗口执行，可独立交付不必等 P13）。
> 来源：PROGRESS 遗留 31——用户 2026-09-24 提问「站点读不到应用表 / 自定义表无对外接口」触发，CodeBuddy 已逐项取证；P12 走查确认**接口本身不缺，缺的是「让模型知道 + 能完成前置 + 拿到凭证」**。
> 编号：D106 / R114~R116 / T116。规模：轻量件（单文档，§4 口径——不动 DB、不动 HTTP 契约、边界清晰，P9 先例）。**AI 工具 37→38；改工具链必跑 `check:ai` + `smoke:ai`（T95 制度）**。

## 1. 背景与问题（取证结论照录）

- **接口不缺**：`/api/pub/app/{pubCode}/**` 五端点已交付（真机 46/46）。
- **模型不知道**：能力清单 `app.data` 行仅述建表/生成管理页，无公开面；站点契约 README（模型改站点前必读）只列 `/api/open/{slug}/api/...`，无公开接口清单与示例。
- **模型拿不到**：app 组 7 工具返回不含 `pubCode`，且无「列应用」只读工具 → 发不出去也拿不到公开凭证。
- **前置完不成**：发布/暴露三开关全在 UI，模型遇「对外展示」只能改道站点并给出冲突答复（实例：会话 #148 字帖应用）。

## 2. 决策

- **D106 范围 = 保守闭环**：W3-a（站点 README 增「数据应用公开接口」节）+ W3-b（能力清单补公开面行）+ **W3-c′（新增只读工具 `list_data_apps`）**；**发布/暴露写工具不进本期**——公开态变更是敏感操作，且 P13 市场状态机（审核/上下架/快照）一到这两个写工具即需重构，现在建是空转。**决策方式：连续两轮 ask_user 均 No preference，按 §7 规程由 Kimi 拍板，责任记我方。**

## 3. 规则

- **R114 `list_data_apps` 只读**：risk=read、perms 空、**零参数**；返回 `{ ok, apps: [{ appCode, name, status, isPublic, pubCode, pubUrl, missing[] }] }`——`missing` = R103 发布缺项清单（与 `GET /api/app/:code/pub-config` 同源逻辑）；只列未删应用（draft 也列，status 标明）；**不代发布**——`missing` 非空时模型输出「去应用中心点『公开』」引导语 + 缺项说明。
- **R115 手册口径**：能力清单 app 组新增 `app.pub` 行（≤50 字）；**通用版不动**（实测 843 字、check:ai 口径 996/1000 仅余 4 字，塞不下一句）；站点契约 README 由 site 域生成模板增节（见 R116）。
- **R116 站点 README 节内容**：① 前置条件（应用中心已发布 ∧ 表/字段已暴露 ∧ display 页已公开——缺一返 40400）② 五端点清单（manifest / pages schema / data list / data detail / file）③ fetch 示例（含 `size` ≤50、`expand` ≤1 层、`filter=字段:eq|contains:值`）④ 错误口径（40400 防探测 / 40001 参数 / 42900 限流，与开放层同款）⑤ 一句话边界：**写永不进公开层，数据录入走应用菜单**。
- **关键词归组纪律**：app 组新增命中词（如「公开/对外/展示应用」）前，先核对 app 组现有 `KEYWORD_TO_GROUPS` 词表与分组优先级——「发布」等泛词已被 siteCms（`publish_site_article`）占用，**不得抢命中**；宁可新词精准（如「公开应用」「应用公开链接」），不用泛词。

## 5. 验收标准

1. **M 用例**：上述提示词 → `ai_tool_call` 出现 `list_data_apps`，返回含 `pubCode/isPublic/missing`；零写副作用。
2. **零回归**：F~L 用例 5/5 不回归；`check:ai` 16/16 → 17 组断言全绿（断言数随工具数增加，照 P11 先例写法）。
3. **手册余量**：新增行后能力清单仍 ≤1200（余量 ~318 字，新行 ≤50 字安全）；通用版 ≤1000 一字不加。
4. **README 落地**：新生成/重建站点 README 含「数据应用公开接口」节，示例 fetch 替换占位符后可直跑。
5. **铁律**：零新依赖；AI 域不直读 app 表（经 AppFacade）；写工具零新增；真实消耗如实登记（M 用例微量）。
