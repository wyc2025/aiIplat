# PRD-P12：数据应用 B 侧（公开数据接口 + 展示页）

> 状态：待实施。上游：PRD-P11（D87~~D96 / R88~~R99 / T100~~T107 已闭环，走查通过）。
> 一句话：给 P11 的数据应用开一扇「只读公开窗」——属主一键发布，匿名访客凭 pub_code 访问公开数据接口与只读展示页，**录入（A）与展示（B）自此共用一份数据**。
> 编号：D97~~D104 / R100~~R108 / T108~~T114；**零新依赖、零新 AI 工具、零新表**。
>
> ⚠ **P14 勘误标注（2026-09-30，Kimi 规格错误认领）**：本文档「匿名公开窗」形态（D98 公开面形态、D99 不建绑定、R107 pub_code 即凭证、R108 display 页口径）系 P12 立项时形态岔路未提出、被越权拍定的**规格错误**，与用户需求口径错配（展示应用=站点静态页 + 授权取数）。已由 **PRD-P14（D112~D118）** 整体修订：匿名端点退役、display 页废弃、授权模型两跳。本文档保留作历史基线；§2/§3 公开面与展示页口径以 P14 为准。遗留 35 已闭环。

## 1. 背景与问题

P11 交付 A 全链后暴露的结构性断层（用户发现，2026-09-23）：站点开放层只覆盖 site/cloud 自有数据（`/api/open/:slug` 的栏目/文章/标签/评论 + `/api/pub` 的云盘 token 公开），应用自定义表只在沙箱 DataService 内可达（登录 + 属主）。「独立菜单录入」与「对外展示」无法共用一份数据。

**定性：非实现偏差，是 D93 划下的 A/B 接缝。** P11 文档明文「不为 B 预留任何端点」；`pub_code`（全局唯一 12 位串）已按 R93 落库备用，注明「P12 公开访问才启用」。本 PRD 即接缝的闭合。

## 2. 决策

- **D97 P12 范围 = 完整 B 侧闭环**：暴露控制 + 公开只读数据接口 + 只读多页渲染，一次打通「录入→展示」。决策方式：连续两轮 ask_user 均 No preference，按 §7 规程由 Kimi 拍板，**责任记我方**。（备选：先薄数据面——展示页手写后将来返工；插队 P13 市场——与当前痛点错配。均放弃。）
- **D98 公开面由应用域自供**：新端点族挂 `/api/pub/app/{pubCode}/**`。与 cloud 的 `/api/pub/f|d/{token}` 同前缀、不同静态段（f/d/app），顶层无参数段，零路由歧义（P4e 遗留 14 教训）；`/api/pub` 语义本就是「平台免登录公开层」，cloud 只是首个租户。站点域、云盘域零改动；app 域读附件流经 CloudFacade 新增最小只读方法（D104）。
- **D99 不建 app_binding 表**：「绑定」落地为**暴露控制三开关**——应用 `is_public` / 表·字段 `is_exposed` / display 页 `is_public`。站点挂载无需绑定表：站点静态页可直接链公开地址；「数据绑定」由页 schema 的 dataSources 本已表达。少建比多建好撤回（D93 同哲学）。
- **D100 防探测口径照开放层先例**：资源类失败（pub_code 不存在 / 应用未公开 / 表未暴露 / 行不存在 / 文件无引用）统一 **40400**；参数校验 **40001**、限流 **42900** 为例外（均为既有码，零新增）。
- **D101 公开发布 = 属主自助开关**，无平台审核；审核归 P13 市场（快照语义随市场一并设计）。
- **D102 display 页复用 P11 区块引擎只读子集**（filterBar / table / detail），rowLink 实现「列表 → 详情」跳转（用户 Q8 口径）；不引入新区块类型、零新依赖。
- **D103 公开数据 v1 = 直读 + 短 TTL 缓存 + 写后失效**；发布快照投影归 P13 市场（审核面天然需要快照，现在建是空转）。
- **D104 公开附件经 `app_attachment_ref` 引用索引 + 暴露校验后流式输出**（MIME 口径同 R26），不改动 cloud 公开机制、不自动 set-public。

## 3. 规则

- **R100 暴露默认关闭**：应用 `is_public=0` / 表 `is_exposed=0` / display 页 `is_public=0`；字段 `is_exposed` 默认 1 但受表门禁。有效暴露 = 应用公开 ∧ 表暴露 ∧ 字段暴露 ∧ 非内部列。
- **R101 公开数据投影白名单**：仅输出已暴露字段 + 内置三件套（`rowId` / `createdAt` / `updatedAt`）；内部列（deleted_at、data 原 JSON、r_cN、属主等）永不输出。
- **R102 display 页校验（R94 扩展）**：kind=display 禁 form 区块与 actions；dataSources 仅 list/get；table 区块禁 rowActions；detail 区块绑 op=get 数据源，rowId 取路由 query（参数名默认 `rowId`）；rowLink 目标页必须存在（同应用内）。
- **R103 发布校验（50012 带缺项清单）**：≥1 张暴露表 + ≥1 个公开 display 页；每个公开页的 dataSources（含 expand 目标）引用表已暴露、引用字段全部已暴露。
- **R104 公开查询固定参数（不开放 DSL）**：page / size（≤50 默认 20）/ sort（`字段:asc|desc`，≤2 组，限暴露字段 + 内置三件套）/ filter（`字段:eq|contains:值`，≤3 组，限暴露字段；contains 限 text/enum）/ expand（≤1 层，限 ref 字段且目标表已暴露；可指定字段子集，服务端仍按白名单裁剪）。违规一律 40001。
- **R105 公开缓存与失效**：键族 `app:pub:{appId}:manifest|schema|data:*`；manifest/schema TTL 600s，data TTL 60s（照开放层热数据缓存先例）；DataService 写路径事务提交后按 appId DEL data 键（SCAN 前缀，键空间按 appId 隔离）；发布/取消/暴露/结构变更即 DEL 对应键（结构变更 piggyback 既有 `app:schema` DEL 事件）。
- **R106 公开端点免登录 `@Public` + `@SkipTransform`**（流式/裸响应照 §16.2 先例）+ 独立限流 60 次/分/IP（照 share-public 30 次/分/IP 先例上调；触发 42900）；管理侧写操作挂 `@OperationLog`。
- **R107 pub_code 即能力凭证**：12 位随机串不猜解；取消公开 / 应用软删即时失效（缓存同步 DEL）；不另发 token、不做可见性分级（分享可见性分级同款挂账）。
- **R108 管理菜单零改动**：display 页不入 userinfo 动态菜单；预览走公开链接（应用中心 / 页编辑器「预览」按钮新窗口打开）。

## 7. 验收标准

1. **发布闭环**：属主发布 → 得公开链接；匿名可访问；取消公开 / 软删应用 → 公开端即时 40400。
2. **防探测**：不存在的 pub_code、未公开应用、未暴露表/字段/行、无引用文件——响应与「不存在」不可区分（一律 40400）。
3. **公开列表/详情**：分页、sort/filter/expand 按 R104 生效；越界参数 40001；响应仅含白名单字段（无内部列）。
4. **n:n 与 expand**：公开列表多值回填与 expand ≤1 层正常；expand 目标表未暴露 → 40001。
5. **display 页校验**：含 form/actions 的 display schema 保存即 50004；发布时数据源未全暴露 → 50012 带缺项。
6. **PublicRenderer**：filterBar/table/detail 三区块只读渲染（无操作按钮）；列表行点击跳详情（rowLink + rowId query）；附件字段出图正常。
7. **附件流**：被引用且已暴露 → inline 正确 MIME（R26 口径：文本强制 text/plain、html/svg attachment）；无引用/未暴露 40400；`?download=1` 出 attachment + 原名。
8. **限流与缓存**：超 60 次/分/IP 触发 42900；数据变更后公开端即时可见（写后 DEL）；manifest/schema 走 600s 缓存。
9. **护栏复用**：公开查询超 2s / 内存路径超 1 万行 → 50009（与 A 侧同护栏）。
10. **端到端（匿名，无 token）**：建应用 → 建表录入（含附件、n:n）→ 建 display 列表页 + 详情页 → 配置暴露 → 发布 → 浏览器匿名访问看到数据与跳转 → 取消公开 40400。
11. **回归**：P11 管理侧零回归（REST 抽测 + userinfo 动态段）；check:ai 16/16、零新 AI 工具、零新依赖。
12. **工程**：双端 tsc/vue-tsc/ESLint 零错 + vite build 通过 + 文档回写（ARCHITECTURE §28 / API §19 / PROGRESS）。

## 8. UI 要点

- **应用中心**卡片/详情：「公开」开关 + 公开链接复制；发布校验未过时按 50012 缺项引导。
- **结构编辑器**：表行与字段行加「公开」标记开关（表关闭时字段开关禁用并提示先开表）。
- **功能页编辑器**：新建可选类型 admin/display；display 页「公开」开关；「预览」新窗口打开公开地址。
- **公开页布局**：独立简洁布局（无管理侧边栏），顶部应用名 + 公开页导航清单。
