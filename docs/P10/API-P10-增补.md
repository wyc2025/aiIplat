# API-P10-增补（AI 对话附件上传·文本类）

> 2026-09-19 ｜ Kimi ｜ 与 PRD-P10-AI-ATTACHMENT.md 配套（编号 D82~~D86 / R82~~R87 / T96~T99）
> 并入主文档时建议作为 **§17**。本期**零新 HTTP 端点、零新错误码、零新依赖**；AI 工具 30 不变（1 个签名变更）。

## 17.1 对话端点变更（修改既有）

### POST /api/ai/chat

请求体加可选字段：

```json
"attachments": [
  { "fileId": "string（云盘文件 id，本地上传先走既有 upload 接口落 /ai-attachments/ 再取 id）" }
]
```

| 约束   | 口径                                                                                                                    |
| ------ | ----------------------------------------------------------------------------------------------------------------------- |
| 数量   | ≤5 个/条消息，超出 → **40001**                                                                                          |
| 单文件 | 本人 + 未删除 + 非目录 + 白名单扩展名（D86）+ ≤2MB；无权/不存在 → **30001**，类型不支持 → **30012**，超 2MB → **30013** |
| 消费   | 由后端按 D83 分流 inject/listed，**上游组装细节对前端透明**；SSE 事件流格式不变                                         |

### GET 会话消息列表（既有，响应扩展）

消息项加 `attachments?: [{ fileId, name, ext, size, chars, mode, path, invalid? }]`（`invalid=true` 表示源文件已删除，前端置灰渲染「源文件已删除」）。

## 17.2 AI 工具契约变更（1 个签名变更，工具总数 30 不变）

### read_cloud_file（修改既有，cloud 组，read 级）

| 项          | 变更                                                                                          |
| ----------- | --------------------------------------------------------------------------------------------- |
| parameters  | 加 `offsetChars?: number`（默认 0）、`maxChars?: number`（默认 20000，上限 50000）            |
| 返回        | 加 `totalChars: number`、`truncated: boolean`、`nextOffset?: number`（truncated=true 时给出） |
| description | 补「大文件请分段读取：先读开头判断结构，再按 nextOffset 续读」                                |

- 旧调用（不传分页参数）行为兼容：等价于 `offsetChars=0, maxChars=20000`——**注意这是行为变化点**（原返回全文 ≤2MB，现默认截到 2 万字符并带 `truncated`），description 与手册须写清，避免模型误以为读到了全文；
- 变更触发 T95 口径：**必跑 `pnpm smoke:ai`**（工具定义变更）。

## 17.3 会话可读清单（无 HTTP 契约变化，行为说明）

system 动态追加（不计手册 2000 字帽，上限 20 条）：

```
用户本会话附带文件（可用 read_cloud_file 按路径分段读取，单次 ≤2 万字符；未读前不得猜测内容）：
- {path}（{name}，{chars} 字符）
- ...
```

## 17.4 错误口径汇总（零新增，全复用）

| 码    | 场景                                     |
| ----- | ---------------------------------------- |
| 30001 | 附件文件不存在/无权/已删除（发送时校验） |
| 30012 | 附件类型不在白名单                       |
| 30013 | 附件 >2MB                                |
| 40001 | 附件数量 >5 / 其他参数错误               |

附件失效（历史轮次重读时源文件被删）**不走错误码**——降级标注，对话不阻断（D82）。
