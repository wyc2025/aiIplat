# PRD-P14　展示应用与数据授权模型修订

> 状态：**已立项（2026-09-30，六项拍板 + bundle 机制经用户逐项确认）**。本文档为 P14 需求基线，实施完成后走查验收。
> 前置：P12 走查「展示页实现与需求偏差」我方规格错误认领（台账 §20）；PROGRESS 遗留 35（2026-09-30 登记）六项拍板项 + 遗留 31（站点内嵌应用数据语义）并入本期。

## 1. 背景与问题

P12 将「对外展示」实现为「应用内 display 页 + 匿名公开窗」（`/api/pub/app/:pubCode/**`），与用户真实口径错配。用户在试用后给出三形态定义并逐项拍板（2026-09-30）：

- **数据应用** = 数据 + 管理页，居后管、一律登录、不公开；
- **展示应用** = 借站点能力由 AI 生成的**原生 HTML 静态页**，默认挂靠一个站点、可换挂靠；
- **合体** = 数据应用**授权**给展示应用后才可读已暴露数据 API。

根因为我方规格错误（P12 立项时形态岔路未提出，D97/D98/D99/R107/R108 越权拍定语义），实现侧忠实执行规格、无实现责任。本期为模型修订期，量级约等于新期。

## 2. 目标 / 非目标

**目标**：三形态落地——展示应用独立实体（自有目录 + 站点挂靠可换）；授权模型两跳（数据应用→展示应用，表/字段级沿用暴露三开关叠加）；站点页经开放层同源相对路径取数、服务端校验授权；匿名公开端点退役；display 页与 PublicRenderer 废弃；市场快照 bundle 化（连展示应用 + 授权一起复制）；AI 侧工具与手册口径同步收敛。

**非目标**：AI 会话模型升级（遗留 32/33/34）；遗留 30 上游 400（reasoning_content 回流）修复——已定案待单独立项；市场版本更新机制（D111 挂账延续）；站点 CMS 本体功能扩充。

## 4. 决策

- **D112（拍板①）**：新增**展示应用独立实体** `disp_display`（owner、name owner 内唯一、site_id 可空、folder 目录、软删状态）。未挂靠态 = 文件存于属主云盘系统暂存区；挂靠 = 文件移入该站点目录。归属**新域 display**（模块 `modules/display/`，两表，经 `DisplayFacade` 对外；site 域开放层与 app 域授权管理均不得直读 display 表——铁律 3/6）。创建入口：AI 工具 `create_display_app`（42）+ 后管最小管理面。
- **D113（拍板②）**：展示页一律为 **AI 生成的静态 HTML/JS 文件**，落展示应用目录、经站点开放层服务；P12 `app_page.kind='display'` 页、`PublicRenderer` 公开渲染、`/api/pub/app/:pubCode/p/:pageCode` 入口**整体废弃**（T127 清理；kind 过滤遗留问题随废弃消失，不单独修补）。
- **D114（拍板③）**：授权两跳——`disp_grant(app_id, display_id)` 唯一对，授权对象是展示应用；表/字段级沿用 P12 暴露三开关叠加（次序见 R125）；后管授权 UI 提供「授权给某站点下全部展示应用」批量快捷项（展开为逐对 grant）。
- **D115（拍板④）**：站点展示页取数走开放层同源相对路径 `/api/open/:slug/api/app/{appCode}/{schema|tables/:t/records|records/:rowId|files/:f/stream}`；服务端校验链（R125），未授权一律 **40400**（不暴露存在性，沿用防探测口径）。`/api/pub/app/:pubCode/*` 五端点**退役**，`pub_code` 停止签发与消费（列保留不删）；`app_def.is_public` 语义转为「**可被授权读取的总开关**」（is_public=0 时授权亦不可读）。
- **D116（拍板⑤）**：换挂靠 = 目录移动 + `site_id` 更新**同一事务**；旧路径即刻 404、新路径即刻 200；一展示应用一站点；未挂靠（暂存区）可挂靠到任一自有站点。
- **D117（拍板⑥）**：市场 **bundle 快照**——提交时自动附带该数据应用的**出边授权闭包**（其授权的展示应用：名称 + 文件 + 授权边），提交确认卡逐条列明；复制时数据应用副本 + 展示应用副本 + 授权关系**在副本之间重建**（授权双方均为接收方实体，跨属主授权问题消解）；**挂靠不随复制**——接收方无站点则副本进未挂靠暂存区，自行挂靠后取数；反向授权边（其他应用→同一展示应用）不带。快照冻结于提交时点。
- **D118**：遗留 31（站点内嵌应用数据语义）并入本期——内嵌 = 静态页内嵌开放层取数调用；PATCH2 的 R116 README 口径与 `list_data_apps` 输出同步重写（不再教模型直链 pubCode）。

## 5. 规则

- **R124（展示文件生成规范）**：AI 生成展示页必须使用相对路径、取数一律经开放层同源路径；禁止硬外链属主站点资源与私有附件（审核关注点；违背后果 = 复制后断链自担，见 R128）。
- **R125（授权判定次序）**：开放层数据端点校验次序固定为 ①站点存在 → ②该站点下存在挂靠展示应用被授予此数据应用（`disp_grant` 命中）→ ③`app_def.is_public=1` → ④表/字段暴露三开关。任一不满足 → **40400**（对外不区分原因）。
- **R126（kind 收缩）**：`app_page.kind` 仅保留 `admin`；存量 `display` 页由迁移登记（清单落工程文档）后删除。
- **R127（换挂靠移动语义）**：目录物理移动与 `site_id` 更新同事务；移动中断 = 全回滚；暂存区与站点目录不得出现同一展示应用双份文件。
- **R128（bundle 边界）**：快照冻结于提交时点，源侧后续授权变更不影响在架条目；只带出边闭包；展示文件断链自担；管理端审核须人工过一遍打包的 HTML/JS 内容。
- **R129（手册预算）**：本期新增两个写工具文本，合注仅余 13 字——**先腾挪既有条目再新增**（重申 R123），交付时附 trim 前后字数对照。

## 7. 验收标准（走查用）

1. 两表迁移生效：前缀、唯一约束（owner+name、app+display）、索引齐备；存量 display 页登记后删除，kind 只剩 admin。
2. 开放层静态路径 `:slug/disp/:id/**` 正确服务展示页文件（HTML/JS/相对资源）；未挂靠或挂靠他站 → 40400。
3. R125 校验链全路径实测：未授权/未公开/未挂靠/表未暴露 → 40400；授权 + is_public=1 → 200；字段级 `is_exposed=0` 的列不出现。
4. 缓存 60s 与写后 DEL、42900 独立限流沿用生效（复用 P12 机制，回归即可）。
5. `/api/pub/app/*` 五端点全部 404；`pub_code` 不再出现在任何新签发物；`is_public=0` 的应用即使已授权亦 40400。
6. PublicRenderer 与 `/p/:pageCode` 入口移除干净；后管 display 页编辑入口消失；生产构建通过。
7. 换挂靠事务性：移动后旧路径 404、新路径 200；中断回滚不留双份。
8. 后管最小管理面可用：创建（工具或 UI）、列表、挂靠/换挂靠、授权/撤权、按站点批量授权。
9. 市场 bundle：含出边闭包的提交快照（确认卡列明）；复制三物化且授权指向副本；接收方无站点 → 未挂靠暂存，挂靠后取数 200。
10. AI 两新工具确认卡落地；`list_data_apps`/README 新口径；`check:ai` 全过且三版手册在帽内（附 trim 前后字数）；`smoke:ai` O 场景全过。
11. 文档回写完成：PRD-P12、PATCH2、PRD-P13 勘误标注指向本文档；台账 §21 记录；角色卡编号与版本行更新。
12. 双端 `eslint` / `vue-tsc` / `tsc` 零错；真实消耗如实登记。
