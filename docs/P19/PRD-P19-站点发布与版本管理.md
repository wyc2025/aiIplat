# PRD-P19 · 站点发布与版本管理

> 版本：2026-10-02 **v2**（采纳外部代码级分析复核修订）· 状态：已拍板
> 依据文档：评估-文件公开与站点托管.md（含 §8 复核增补）；外部代码级架构评估（2026-10-02 用户提供，代码行号事实待实施时验证）
> 拍板内容：①立项完整版（快照发布 + 版本管理页 + 预览保留）；②Phase1 快照仍经 Nest 服务，nginx 直出挂账 Phase2；③公开判定链冲突独立为 **W12 先行修复**，本期 legacy 轨继承其语义。
> 编号续接：D143~~D151 / R156~~R161 / T159~T164 / 错误码 +40121。

## 1. 背景与问题

- 现状（P14 起）：站点 = 云盘工作副本直挂公网（`/api/open/:slug/{*path}` 实时读云盘存储出流）。
- 病灶（评估报告 §4 + §8 复核，三条）：
  1. **权限平面耦合**：`cloud_file.is_public` 一个开关同时承担「云盘分享可见」与「站点可访问」两个信任域——用户为让页面可访被迫显式公开，同时暴露给云盘公开链，属权限放大（外部代码级发现，我方原评估未覆盖，认领）；
  2. **写入非原子**：writeFiles 逐文件循环 + 部分成功语义——AI 写 5 个文件第 3 个失败，线上立刻半成品且访客可见；
  3. **无发布闸门/无回滚/故障域耦合**：误保存、云盘移动/删除零延迟直达公网；no-cache 被迫统一（D28），长缓存/直出无从谈起。
- 本阶段引入业界不可变部署模型的最小同构实现（纯静态，无构建步）：**发布 = 不可变快照 + 指针翻转；勾选历史版本 = 原子切换/秒级回滚；工作副本保留为预览轨。** 三条病灶一次解决：快照轨只认 release 不消费 is_public（解耦 1）；快照+指针翻转（解耦 2）；快照隔离云盘操作（解耦 3）。

## 2. 范围

**做：**

1. `site_release` 表 + `site.active_release_id` 指针列（迁移安全：加列可空）。
2. 发布端点：整树快照（临时目录 + rename 原子化 + manifest 记 contentHash）→ 发布即上线。
3. 版本管理：列表 / 切换（activate）/ 锁定（pin）/ 删除端点 + 站点管理页「发布与版本」面板。
4. 开放层双轨解析：有当前版本 → 快照轨（**不消费 is_public**，权限平面解耦）；从未发布 → legacy 直挂（向后兼容，继承 W12 阻断优先语义）。
5. 管理态预览端点：读工作副本，编辑器/AI 迭代体验不变。
6. 保留策略：未锁定版本每站点上限 20（可配置），当前版本与锁定版豁免。
7. 快照范围 = 站点根子树**全量含 media/**（否则发布后图片丢失）；展示应用 `disp/` 托管链**不进**快照（独立授权链，避免双版本语义纠缠）。
8. **AI 工具文案同步（D151，v1 漏项认领）**：`write_site_files` 等工具的描述与结果文案改为草稿语义（「已保存，发布后访客可见」），**禁止声称「已上线」**；必跑 `pnpm check:ai` + `pnpm smoke:ai`（T95 制度）；文案改动先算手册余量（合注帽 2000 字，余量 ~7 字，只许腾挪不许超）。
9. 冒烟 `smoke:site` + 验收执行。
10. 顺带关闭：P18-C1（TTL 自然过期用例条目化）、P18-S1（PROGRESS 文末过期 zod 行删除）。

**不做（非目标，挂账 Phase2/未来）：**

- nginx / 对象存储直出快照 + 长缓存策略（Phase2，与 MinIO/OSS 切换同行）。
- 快照物理去重（manifest 记 contentHash 已为其铺路；refcount GC 复杂度不值当前规模）。
- 版本 diff 视图、独立沙箱域（github.io 式）、公网草稿预览环境。
- 文件公开小加固（评估报告 G2/G3/G5）与 nginx gzip/br（纯运维配置，用户随时可做）。

## 4. 功能需求

- **FR1 发布**：站点管理态发起，可填备注 label；快照 = 站点云盘目录全量子树复制（含 media/，排除 disp 托管链）；完成后指针翻转即上线；返回版本信息（序号/文件数/总字节/时间）。
- **FR2 版本列表**：展示 序号 / 时间 / 发布人 / label / 文件数 / 总字节 / 是否当前 / 是否锁定。
- **FR3 切换**：勾选任一历史版本为当前版本，即时生效，可反复横跳（=回滚）。
- **FR4 锁定/删除**：锁定版豁免自动清理；当前版本不可删；删除即清理对应快照目录。
- **FR5 保留**：发布新版本后检查，未锁定版本超上限时自动清理最旧（当前版本豁免）。
- **FR6 预览**：管理态预览端点服务最新工作副本（需登录 + 站点权限）。
- **FR7 兼容**：从未发布过的站点，正式位维持现状直挂工作副本（legacy 轨，公开判定遵循 W12 阻断优先）；管理页对这类站点提示「当前为草稿直出，建议发布」。
- **FR8 AI 文案**：AI 写站工具的对外表述与结果文案明确「保存到工作区，发布后访客可见」，不得暗示即时上线。

## 5. 验收标准

| #   | 验收项                                                                                                                                    | 证据方式                   |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| 1   | **隔离性**：发布 v1 后修改工作副本文件，`/api/open/{slug}/**` 内容不变                                                                    | 冒烟：发布→改文件→GET 比对 |
| 2   | **预览轨**：管理态预览端点立即读到修改后内容；未登录访问被拒（401/403 按管理态惯例）                                                      | 冒烟 + 负例                |
| 3   | **发布即上线**：发布后 active 指向新版，序号/文件数/总字节/manifest 与实际目录一致；media/ 内文件可在正式位访问                           | 冒烟 + 库行核对            |
| 4   | **回滚**：activate v1 后正式位服务 v1 内容；再切回 v2 恢复；指针可反复                                                                    | 冒烟                       |
| 5   | **并发互斥**：同站双并发发布，其一 40121；无残留 .tmp 半成品目录                                                                          | 冒烟（并发脚本）+ 目录检查 |
| 6   | **保留策略**：连续发布超上限，最旧未锁定版自动清理；锁定版豁免；当前版本不可删                                                            | 冒烟（调小 KEEP 值跑）     |
| 7   | **向后兼容**：从未发布的站点正式位仍直挂工作副本（W12 语义）；disp 托管链行为不因发布变化                                                 | 冒烟                       |
| 8   | **安全负例**：构造路径穿越/直接访问 site-releases 区或 .tmp 目录 → 40400；无站点权限用户调 publish/activate → 403                         | 冒烟负例段                 |
| 9   | **权限解耦负例**：已发布站点中，将工作副本某文件 is_public 置 2（阻断），正式位已发布快照内容**不受影响**仍可访问                         | 冒烟（R161 直接证据）      |
| 10  | **AI 文案与门禁**：write_site_files 结果文案为草稿语义、无「已上线」表述；`pnpm check:ai` + `pnpm smoke:ai` 全绿；手册合注 ≤2000 字不破帽 | 终端输出 + 文案核对        |
| 11  | **工程门禁**：`pnpm smoke:site` 全绿；既有 smoke:ext/smoke:mcp 不回归；前端 `vite build` 通过                                             | 终端输出                   |

## 6. 风险与对策

| 风险                  | 对策                                                                       |
| --------------------- | -------------------------------------------------------------------------- |
| 发布中断留半成品      | .tmp + rename 模式；失败路径强制清理（R157）                               |
| 双轨解析引入缓存错乱  | site:path 缓存按轨维度失效，发布/切换/删除三事件全覆盖（R159）             |
| 存储膨胀              | 上限 20 + 站点配额计入；物理去重挂账 Phase2                                |
| AI 误导用户「已上线」 | FR8 + 验收 #10（v1 漏项，外部分析补上，认领）                              |
| W12 收紧影响存量站点  | W12 自带存量扫描 → 报告 → 用户确认 → 合入；P19 legacy 轨直接继承修复后语义 |
