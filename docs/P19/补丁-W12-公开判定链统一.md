## 1. 问题

存在两套公开判定链，规则相反（外部引用证据：`cloud-facade.service.ts:229-242` vs `pub.service.ts:186-199`）：

| 链路                                                   | 现行规则                                                                                |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------- |
| `/api/open/**`（站点，resolvePublicPath）              | 从目标上溯，**遇第一个非 0 节点定生死** → 文件自身 `is_public=1` 可穿透父级 `2`（阻断） |
| `/api/pub/**`（云盘公开链，assertAncestorsNotBlocked） | 上溯，**任一祖先 2 即阻断**                                                             |

后果：同一个文件，`/api/pub` 判不可见、`/api/open` 判可见——**权限结论不可推理**。用户把父目录设为「阻断」的本意是「这里面都别外传」，但只要某子文件曾被单独设过公开，站点侧仍能读到它。这是漏洞不是配置问题。

## 2. 修复规格

1. **统一为阻断优先**（S3 explicit deny 同构，业界通行）：`/api/open/**` 判定链改为——从目标上溯，祖先链（含自身）**任一节点 = 2 即阻断**；无 2 时，再按现行继承规则判定（目标或最近非 0 祖先 = 1 则可见，全 0 按站点级默认规则）。
2. `/api/pub/**` 链**不动**（已是阻断优先）。
3. 「取消公开落库为 2（显式阻断而非回继承）」的既有语义**维持不变**（本就更安全）。
4. 文件自身 1 不再穿透父级 2——这是本补丁唯一的行为收紧点。

## 3. 验收标准

| #   | 验收项                                                                                                                                          | 证据方式                |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------- |
| 1   | **穿透负例（核心）**：父目录 = 2、子文件 = 1 → `/api/open` 与 `/api/pub` **均** 40400（收窄类纪律：调用方试图绕过负例）                         | 冒烟                    |
| 2   | **继承正例**：全 0 链 + 站点/分享既有可见性不变                                                                                                 | 冒烟回归                |
| 3   | **显式公开正例**：文件 = 1 且祖先链无 2 → `/api/open` 可见                                                                                      | 冒烟                    |
| 4   | **存量扫描**：脚本扫描全部站点树中「祖先 = 2 且后代 = 1」的组合 → 出报告 → **用户确认后再合入**（行为收紧可能影响现存站点，个人平台量级应很小） | 扫描报告 + 用户确认记录 |
| 5   | 回归：smoke:ext / smoke:mcp 及站点相关冒烟全绿                                                                                                  | 终端输出                |
