## 二、发现与修复指令（10 处）

### 【高】W1. §13.14「列表风格约定」没有权威落点

**事实**：ARCHITECTURE-P3-增补.md 头部声明"内容已完整并入 ARCHITECTURE.md……本文件不再作为权威源"，但 §13.14（分页 PageResultDto / 非分页裸数组 / 附带数据才包对象 / 时间列必须 formatTime）是 **2026-08-28（T32）才追加进增补的，晚于 2026-08-27 的并入标注**——主文档全文 grep 不到「裸数组 / formatTime / 附带数据」任何一条。而 T39 验收自查明确引用"列表风格遵守 §13.14"。后果：只读主文档的人（或 AI）永远不知道这条纪律，而它正是 P2a 联调踩过的坑（裸数组被当 PageResult 解析）。

**修复（CodeBuddy 执行）**：

1. 主文档 ARCHITECTURE.md 在 §12 之后、§14 之前插入新章节，章节号正好补上 §13 断档：

```markdown
## 13. API 列表风格约定（P3 增补 §13.14 并入）

1. **分页列表**：返回 `PageResultDto`（`{ list, total, pageNo, pageSize }`）
2. **非分页列表**（树平铺、字典、不分页关联数据）：返回**裸数组** `[...]`，前端直接接数组，禁止套 `{ list: [...] }` 壳
3. **附带数据才包对象**：列表之外还要携带聚合/附加字段时（如 `{ list, summary }`），才允许包对象
4. **时间列**：接口返回 ISO 8601 字符串，前端表格/详情展示**必须**经 `formatTime`（dayjs）格式化，禁止 prop 直出原始值
5. 前端取数类型必须与后端实际返回形态一致（裸数组就接 `T[]`，禁止按 `result.list` 取裸数组接口）
```

2. ARCHITECTURE-P3-增补.md 头部并入标注追加一行：`- 列表风格约定（§13.14，2026-08-28 追加）→ ARCHITECTURE.md §13（2026-08-29 补并入）`

### 【中】W2. API.md 未同步 is_public 三态语义；file.list 的 isPublic 口径缺失且有行为陷阱

**事实**：三态修订（PROGRESS 修订记录）只回了架构文档，API.md 全文 grep 不到「三态/继承/有效公开」。具体三处缺口：

- §6.4 set-public 仍写"仅标记自身（公开性向下级联）"，**没写 API 契约二元值到落库三态的映射**（`isPublic=0` 落库 `2`=显式阻断，不是回到继承态）
- §6.4 file.list 只写"item 新增 isPublic 字段"，**未写口径**；实现是 `isPublic: f.isPublic === 1`（原始列布尔化）
- **行为陷阱**：三态下布尔返回值丢失信息——`0=继承`（站点根下实则公开可访问）与 `2=阻断`（公开目录下 404）在前端都显示"无标签"，无法区分；且对继承态文件点"设为公开→取消公开"两步操作后，文件从"可访问"变成"已阻断 404"，用户无感知

**修复（文档立即改 + 代码小改并入 P4b T43）**：

1. API.md §6.4 set-public 行改为：

```markdown
| POST | /api/cloud/file/set-public | cloud:file:public | 入参 `{ id, isPublic }`（1=设为公开 / 0=取消公开）；仅标自身不级联写。落库三态（R2 修订）：1→`1` 显式公开；0→`2` 显式阻断（**不是回到继承态**——公开目录下"取消公开"的语义即"此项目录内阻断"，祖先公开也不再继承）；新建文件默认 `0`=继承父目录。访问时上溯判定：遇第一个非继承节点定生死。挂 @OperationLog |
```

2. file.list 行改为（配合 T43 代码改）：

```markdown
| GET | /api/cloud/file/list | cloud:file:list | item `isPublic` 返回**原始三态 int**（0=继承 / 1=显式公开 / 2=显式阻断）；前端标签：1→「公开」、2→「已阻断」、0→无标签。有效公开性（祖先链裁决）不在列表逐行计算，以开放层访问结果为准 |
```

3. 代码小改（写入 PRD-P4B T43 任务）：`file.list` 的 `isPublic: f.isPublic === 1` 改为 `isPublic: f.isPublic`；前端云盘页标签判断同步改为 `=== 1` / `=== 2` 双标签。属自有前端同步的口径收窄，无第三方调用方。
