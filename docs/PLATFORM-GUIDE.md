# iplat 平台使用手册（AI 助手版）

> 本文件供 AI 助手注入 system prompt 使用，帮助用户了解和使用 iplat。
> 维护纪律：功能上线或变更必须同步更新本文件；只写"是什么、在哪、怎么操作、有什么限制"，总长 ≤2000 字。

## 平台简介

iplat 个人平台，含后台管理底座与 AI 助手。"用户-角色-菜单"RBAC：用户绑角色，角色绑菜单与按钮权限，登录后只见有权限的功能。

## 系统管理（左侧菜单"系统管理"）

### 用户管理（系统管理 → 用户管理）

- 新增用户：点"新增"，填用户名、密码（8~32 位含字母数字）、昵称等，选择部门和角色后保存
- 分配角色：用户行"分配角色"按钮，弹窗中勾选一个或多个角色
- 禁用/启用：用户行的状态开关；禁用后该用户无法登录
- 重置密码：用户行操作，生成随机 8 位新密码，仅展示一次
- 删除用户：有确认框；内置管理员 admin 不可禁用、删除、改角色

### 角色与权限（系统管理 → 角色管理）

- 新增角色：填角色名和标识（如 finance）
- 分配权限：角色行"分配权限"，弹出权限树（三级），勾选保存；该角色用户下次请求生效
- 权限最小单位是"按钮"，如"用户管理-新增"对应权限标识 system:user:create
- 角色被用户引用时不可删除；admin 角色不可编辑、删除

### 菜单管理（系统管理 → 菜单管理）

- 维护全部页面与按钮权限：目录 → 菜单（页面，配路由与组件路径）→ 按钮（权限标识）
- 新增页面型功能的标准动作：在菜单管理中新增菜单 → 到角色管理中给角色勾选 → 用户刷新后可见
- 菜单有子级时不可删除

### 部门与字典

- 部门管理：树形组织结构，用户可挂到部门下；有子部门或有关联用户时不可删除
- 字典管理：左侧字典类型、右侧该类型的数据项，用于维护"状态、性别"这类通用枚举

### 日志（系统管理 → 日志管理）

- 登录日志：谁在何时何地登录成功/失败
- 操作日志：谁在何时对哪个模块做了什么操作（仅记录增删改类操作）

### 在线用户（系统管理 → 在线用户）

- 查看当前在线用户（实时，保留最近 30 分钟活跃会话）
- "踢下线"可强制某用户退出登录（admin 不可踢）

## AI 助手（左侧菜单"AI 助手"）

- AI 对话：多会话、流式输出、切换大模型（以"模型选择器"为准）。部分模型支持工具调用（查数据、执行操作）
- 开通套餐：AI 功能需开通套餐才能使用；套餐决定每月积分额度，对话按实际 token 用量扣积分
- 我的用量：查看当前套餐、剩余积分和每次对话的扣费明细

## 个人网站（左侧菜单"个人网站"）

- 站点设置：每用户一个站点（静态托管+文章）。填 slug（3~32 位小写字母/数字/连字符）建站：云盘出现"我的站点"公开目录（含模板与 media/），访问地址 `/api/open/{slug}/`；可改标题/描述/slug（旧地址立即失效）与评论审核开关
- 栏目/标签/文章/评论：文章支持三级栏目、多标签、markdown 正文、封面（存 media/）、草稿与发布；下架不可见；评论经"评论管理"审核后展示（可关闭审核）
- 文件管理：站点文件即云盘"我的文件"里的文件——上传/编辑即改站点（文本文件点「编辑」在线改，保存即生效）；"设为公开"的目录经公开地址访问，"取消公开"最长 60 秒生效
- 模板库：站点设置页可选默认博客/作品集/名片站一键应用；同名文件覆盖（旧版进回收站可还原），media/ 与模板外文件不动
- 开放接口：站点代码以相对路径 `./api/*` 读站点数据并提交评论（模板即示例）；页面在安全沙箱中（读不到平台凭证），可用 alert/confirm 反馈
- AI 站点工具：list_site_files 列文件、read_site_file 读文本、write_site_files 批量写（需确认）；动手前 read README.txt（API 契约）；仅写文本，图片上传 media/

## 云盘（左侧菜单"云盘"）

- 我的文件：多选或拖入批量上传（并发队列，拖文件夹请压缩后用"解压"）；文本可在线编辑；zip 可一键解压到同名文件夹；同名自动 "(1)"，勾选"覆盖同名"则替换
- 分享：创建限时下载链接（分享管理可停止/延长）
- 公开链接：文件/文件夹可设为公开，得免登录在线查看的 /view/ 链接；取消公开后旧链接立即失效，重新公开生成新链接；文件夹可关"允许访客浏览列表"
- 回收站：删除项可还原或彻底删除

## 个人中心（右上角头像 → 个人中心）

- 修改个人资料（昵称、邮箱、手机、性别）
- 修改密码：需输入旧密码；修改成功后所有设备强制重新登录

## 常见规则与限制

- 初始管理员：admin（超管，拥有全部权限，不可被禁用/删除）
- 忘记密码：目前只能由管理员在用户管理中重置
- 权限问题先确认：用户角色是否已分配对应菜单/按钮权限
