## 1. 需求背景

平台三大规划能力中云盘最先落地（个人网站在其后）。云盘让每个注册用户拥有私有文件空间，是后续"AI 管理文件""AI 生成站点资源托管"的存储底座。交互对标操作系统文件管理器：双击进入、面包屑路径导航、回退上一级。

## 2. 范围

### 本期做

- 我的文件：目录树浏览（面包屑/双击/回退）、新建文件夹、上传、下载、预览、重命名、删除
- 公开链接：创建（选有效期）、列表、停止公开、延长时间、免登录访问下载
- 回收站：顶层被删项列表、浏览被删文件夹（只读）、还原、彻底删除、清空回收站
- 配额：1GB 默认、上传校验、用量展示、admin 调整
- cloud_file / cloud_share / cloud_usage 三张表
- 内容审核状态机字段与分享门禁（引擎下期）

## 3. 功能细则

### 3.1 F1 我的文件（菜单：云盘管理/我的文件，cloud:file:list）

**页面布局**

```
┌──────────────────────────────────────────────────────┐
│ [← 回退]  我的文件 / 资料 / 合同      [新建文件夹] [上传] [回收站] │
│        （面包屑，每段可点击）                            │
├──────────────────────────────────────────────────────┤
│  图标  名称            大小        修改时间          操作     │
│  📁   设计稿           —         08-20 10:00    重命名 删除    │
│  📄   简历.pdf        1.2MB      08-25 14:22    预览 下载 分享 重命名 删除 │
└──────────────────────────────────────────────────────┘
```

**交互规格（类 OS，铁律）**

- 双击文件夹 → 进入下一层；双击文件 → 打开预览弹层
- 触屏设备单击 = 进入/预览
- 回退按钮 = 上一级（根目录时禁用）；面包屑每段可点击跳转
- 当前目录同步 URL `?parentId=xxx`，刷新/分享页面链接后停留在原位置
- 列表排序：**文件夹恒在文件前**；组内可按名称/大小/修改时间排序（点击表头）
- 每行显示类型图标（不加载缩略图/原图）；文件显示大小，文件夹显示"—"
- 空目录展示空态提示"暂无文件，点击右上角上传"
- 配额展示：工具栏右侧或页面角落显示"已用 256MB / 1GB"（进度条形式）

**操作与权限对照**

| 操作                | 权限标识           | 说明                                        |
| ------------------- | ------------------ | ------------------------------------------- |
| 进入/浏览/预览/下载 | cloud:file:list    | 登录用户的基础能力                          |
| 上传                | cloud:file:upload  | 上传到当前目录                              |
| 新建文件夹          | cloud:file:mkdir   | 弹窗输入名称（复用 FormDialog 范式）        |
| 重命名              | cloud:file:rename  | 文件/文件夹通用                             |
| 删除                | cloud:file:delete  | 移入回收站（软删），ElMessageBox 确认       |
| 分享                | cloud:share:create | 仅文件行显示；弹窗选有效期 → 生成链接并复制 |

### 3.2 F2 公开链接（菜单：云盘管理/公开链接，cloud:share:list）

标准列表页（**复用 ProTable**）：文件名、链接（可点击复制）、访问次数、创建时间、过期时间、状态（有效/已过期/已停止）。

行操作：

- **停止公开**（cloud:share:stop）：确认后链接即刻失效
- **延长时间**（权限同 cloud:share:stop）：弹窗选档位，从 max(now, expireAt) 续期；**已过期可延长**（从当前时间续档），**已停止不可延长**（按钮置灰）
- **复制链接**：`{前端origin}/share/{token}`

**访客侧（免登录）**：打开链接 → 展示文件名/大小/过期时间 + 下载按钮；链接失效 → 友好提示页。此页面为**独立极简路由**（不进后台布局）。

### 3.3 F3 回收站（菜单：云盘管理/回收站，cloud:recycle:list）

- 列表展示**顶层被删项**（被删文件/文件夹；若某文件夹被删，其内部项不单独列出）
- 双击被删文件夹 → 进入浏览其内容（面包屑交互同我的文件），但**只读**：行内无操作按钮，不允许再删/重命名
- 行操作：**恢复**（cloud:recycle:restore）、**彻底删除**（cloud:recycle:delete，红色按钮 + 确认文案"删除后不可恢复"）
- 页面级：**清空回收站**按钮（cloud:recycle:delete，二次确认"将永久删除 N 项"）
- 恢复后 toast 提示还原位置（原位 / 根目录）

### 3.4 F4 admin 调整配额（入口：系统管理/用户管理 行操作新增按钮，cloud:quota:update）

用户管理列表操作列新增"配额"按钮 → 弹窗（复用 FormDialog）显示当前用量"已用 X / 配额 Y"，可修改配额（单位 GB，下限 = 当前已用量）。挂 @OperationLog。

### 3.5 F5 个人中心头像上传（P1 遗留补做）

个人中心头像区域支持点击上传（jpg/png/webp，≤5MB），上传后即时刷新；复用 system 域既有上传能力。

## 4. 业务规则（违反任何一条视为 bug）

- **R1 数据隔离**：每用户一棵独立文件树（根 parent_id=0），一切接口只操作当前用户的数据；操作他人资源一律按"不存在"处理（30001），不泄露存在性
- **R2 删除语义**：删除 = 软删（写 deleted_at），**只作用于被选项自身**，后代项不变（随父不可见）；回收站只列"顶层被删项"（自身已删且所有祖先未删）
- **R3 配额记账**：上传成功 used+=size；**彻底删除** used-=size；软删/还原不动 used（回收站占配额）；used 永不为负（兜底）
- **R4 同名规则**：同目录下同名判定排除回收站项；上传/还原冲突自动追加"(1)"、"(2)"；重命名冲突返回 30002 阻止
- **R5 还原规则**：父目录存在且未删 → 还原原位；父目录不存在或已删 → 落到根目录，响应 message 说明；还原同样只作用于该项自身
- **R6 限制**：名称 ≤64 字符；目录深度 ≤10 层；单目录 ≤500 个直接子项；单文件 ≤100MB；超出一律拒绝（30006/30004）
- **R7 预览白名单**：图片（jpg/jpeg/png/gif/webp）、文本（txt/md/json/js/ts/vue/css/xml/yml/log，≤2MB）、PDF、mp4、mp3；其余类型预览请求返回 30005，前端提示下载。**文本类预览一律以 `text/plain` 返回**（防 html/svg 携带脚本造成 XSS），svg/html 不在白名单内
- **R8 分享规则**：仅文件可分享（30009）；链接有效期内且未停止且**文件未被删除**才可访问；文件彻底删除时连带删除其全部分享记录；访问成功 visit_count+1
- **R9 审核门禁**：分享创建时若配置开关开启且文件 audit_status≠1（通过）→ 拒绝（30010）；本期开关默认关闭；文件默认 audit_status=0
- **R10 删用户预检**：system 域删除用户前经 cloud 域门面 `hasFiles(userId)` 询问，存在文件（含回收站）则阻止删除并提示先清理

## 6. 验收标准

- [ ] 新建文件夹"资料"，双击进入，面包屑显示"我的文件 / 资料"，回退返回根目录；刷新页面后仍在"资料"目录
- [ ] 上传多个文件到当前目录，进度条可见；同名文件自动变为"xx(1)"；列表文件夹在前
- [ ] 双击图片/PDF/MP4 正常预览；双击 .zip 提示"请下载查看"；视频预览可拖动进度条
- [ ] 下载文件内容与上传一致（比对大小/哈希）
- [ ] 上传使配额超限时拒绝并提示 30003；删除入回收站后用量不变，彻底删除后用量回落
- [ ] 删除文件夹"资料"→ 回收站出现"资料"且其内部文件不单独出现；双击可只读浏览其内容
- [ ] 先删文件 A、再删其父目录 B：回收站只见 B；恢复 B 后 A 重新出现在回收站（R2 语义）
- [ ] 恢复"原父目录已被删"的文件 → 落到根目录并提示；重名还原自动加"(1)"
- [ ] 文件创建 7 天公开链接 → 无痕浏览器（免登录）可查看信息并下载，访问次数 +1；停止公开后访问提示失效；文件彻底删除后链接同步失效
- [ ] 文件夹行无"分享"按钮（或点击返回 30009）
- [ ] admin 在用户管理将某用户配额改为 2GB，该用户配额展示与上传校验同步生效
- [ ] 个人中心上传头像成功，刷新后头像保持
