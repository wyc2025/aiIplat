# API-P17 增补（§24：scope.rowFilter 契约）

版本：2026-10-02 ｜ 对应 PRD-P17；本节为 API.md §24 的入库蓝本。
未出现的语义以 §22（REST 对外契约 v1）与 §23（MCP）为权威。

---

## §24.1 scope JSON 结构（槽位启用，DDL 不变）

```json
{
  "tables": ["book"],
  "fields": { "book": ["title", "status", "cover"] },
  "ops": ["read"],
  "rowFilter": { "book": ["status:eq:published"] }
}
```

- `rowFilter`：`{ [表名]: ["字段:算子:值", …] }`，可缺省 / null（不过滤，现行行为）；每表 ≤3 条；表内多条件 AND。
- 语法与算子集：**同 R104 请求 filter**（同一解析器）。
- 约束：表 ∈ `scope.tables`；字段 ∈ 该表 scope 字段口径（`fields` 未配 = 该表全部已暴露字段可选）且在暴露开关内——**禁止引用不可见字段**。

## §24.2 管理侧端点行为（端点号沿用 §22.1，零新增）

| 端点                                        | 变化                                                                             |
| ------------------------------------------- | -------------------------------------------------------------------------------- |
| `POST /api/access/credentials`（创建）      | body `scope.rowFilter` 启用；非法 → **50021**，errmsg 指明条目（表.字段 + 原因） |
| `PUT /api/access/credentials/:id`（编辑）   | 同上                                                                             |
| `GET /api/access/credentials*`（列表/详情） | 响应 `scope.rowFilter` 原样返回                                                  |

校验顺序：tables → fields → ops → **rowFilter**（R147 逐条）。

## §24.3 对外取数行为变化（REST §22.2 与 MCP §23.3 同源）

- records：rowFilter 强制 AND 注入；与请求 `filter` 参数取交集；冲突 → code 0 空页。
- detail：行不满足 rowFilter → **40400**（与不存在同表现）。
- schema：不变（rowFilter 不在 schema 投影内，不下发——**过滤条件本身不对外泄露**）。
- 附件流（W11 收窄后）：引用行的表·字段 scope 交集判定不变；rowFilter 不参与附件判定（附件随记录可见性，记录因 rowFilter 不可见时其 fileId 本就不会出现在该凭证的结果里）。
- 游标 / 排序 / 配额 / 审计口径：全部不变。

## §24.4 运行期失效（R149）

rowFilter 引用的表/字段在签发后被下线或取消暴露 → 该表 40400（判拒，非跳过）；恢复暴露即自愈。

## §24.5 错误码（零新增）

| 码    | 场景                                                                  |
| ----- | --------------------------------------------------------------------- |
| 50021 | 管理侧 rowFilter 非法（表/字段/算子/值类型/超 3 条），errmsg 指明条目 |
| 40001 | 请求 filter 参数自身违例（既有口径）                                  |
| 40400 | 行不满足 rowFilter / 运行期失效判拒 / 越权（既有口径）                |

下一可用仍为 50022。
